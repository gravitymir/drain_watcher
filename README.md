# drain_watcher

Логгер тока утечки автомобильного аккумулятора: шунт в минусе аккумулятора,
плата-датчик на INA228 снимает с него напряжение и отдаёт замеры по I2C внешнему
контроллеру (ESP32 и т.п.). Контроллер питается от пауэрбанка, поднимает точку доступа
Wi-Fi и отдаёт веб-страницу с историей.

- [`hardware/`](hardware/) — плата KiCad 10 (схема, разводка, гербера, BOM/CPL для JLCPCB)
  и скрипты, которые её собирают. Подробности — в [hardware/README.md](hardware/README.md).
- Прошивка (Rust) — будет здесь же.
